# iphone-15-pro-cad
CAD design of iPhone 15 Pro — created through Onshape.

This is a basic replica of the iPhone 15 Pro hardware design created through Onshape by Young Lim. The model contains mathematically accurate positions of each elements of the device, with the exception of the bottom speakers (I highly recommend editing those by yourself if you are not satisified with their positions).
